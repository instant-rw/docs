This guide takes an app from your code to a live HTTPS address on Instant Cloud. You need an Instant account: log in at [instant.rw/login](https://instant.rw/login) with GitHub or your email, and your account is created the first time. Then choose a plan for your organization in **Billing**; plans start at RWF 5,000 a month. See [Plans and billing](/account/billing).

Pick the way you want to deploy. All three end with the same app in your dashboard.

<Tabs>
  <Tab title="Dashboard">
    <Steps>
      <Step title="Create an application">
        In the [dashboard](https://instant.rw/dashboard), open **Applications** and select **New application**.
      </Step>
      <Step title="Choose your code">
        Under **Import a repository**, select **Connect GitHub** and install the Instant GitHub app on the account or organization that owns the repository. Then pick the repository.

        No repository? Drag your project folder or a `.zip` onto **Upload a folder** instead. See [Deploy without Git](/deploy/without-git).
      </Step>
      <Step title="Check the settings">
        Instant detects the framework and fills in the build and start commands. Choose a region and a size, and open **Environment** to add any variables your app needs.
      </Step>
      <Step title="Deploy">
        Select **Deploy** and follow the build log. When the build passes, the app is live at `<app-name>.instant.rw`.
      </Step>
    </Steps>

    From now on, every push to the production branch deploys automatically.
  </Tab>
  <Tab title="CLI">
    <Steps>
      <Step title="Install the CLI">
        ```sh
        curl -fsSL https://instant.rw/install.sh | sh
        ```

        On Windows, or to install with npm, see [CLI](/cli/overview#install).
      </Step>
      <Step title="Sign in">
        ```sh
        instant login
        ```

        Your browser opens. Check that the code matches and approve it.
      </Step>
      <Step title="Deploy your project">
        ```sh
        cd my-project
        instant deploy
        ```

        The first time, the CLI offers to create a new app or link an existing one. It then uploads your code, streams the build log and prints the live address.
      </Step>
    </Steps>
  </Tab>
  <Tab title="AI agent">
    <Steps>
      <Step title="Connect your agent">
        Add Instant to Claude, ChatGPT, Cursor, Codex or another MCP client with the URL `https://mcp.instant.rw/mcp`. See [Connect a client](/agents/connect) for each one.
      </Step>
      <Step title="Sign in and allow access">
        Your client opens Instant in the browser. Sign in, choose the organization and select **Full access** so the agent can deploy.
      </Step>
      <Step title="Ask it to deploy">
        For example:

        > Deploy my GitHub repository acme/shop on Instant, add a PostgreSQL database for it and tell me the address when it's live.

        The agent creates the app, starts the deployment and reads the build log if anything fails. To deploy from GitHub, the Instant GitHub app must be installed on the repository's account; for code that isn't on GitHub, the agent runs `instant deploy` with the [CLI](/cli/overview).
      </Step>
    </Steps>
  </Tab>
</Tabs>

## If the build fails

Open the deployment in the dashboard. The log shows where the build stopped, and when Instant recognises the problem, such as a lockfile that doesn't match or a missing registry token, a **Suggested fix** card explains it. See [Builds](/deploy/builds#when-a-build-fails). Your previous deployment keeps serving traffic until a new one passes, so fix the code and deploy again.
