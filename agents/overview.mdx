Instant Cloud has an MCP server, so AI clients such as Claude, ChatGPT, Cursor and Codex can work with your apps, databases, buckets and domains. Ask in plain words, for example "why did my last deploy fail?", and the agent reads the logs, explains the problem and, with your permission, fixes it.

The server URL is `https://mcp.instant.rw/mcp`. Your client signs in through the browser, so there is no key to copy. See [Connect a client](/agents/connect) for each client's setup.

## What an agent can do

You choose one of two access levels when you connect.

<Columns cols={2}>
  <Card title="Full access" icon="pen">
    Deploy, roll back, scale, pause and resume apps. Change settings and environment variables. Create databases, buckets and domains and connect them to apps. Take database backups.
  </Card>
  <Card title="Read only" icon="eye">
    See apps, deployments, databases, buckets, logs, metrics and usage. Secret values stay hidden, and database queries run in a read-only transaction.
  </Card>
</Columns>

The [tool reference](/agents/tools) lists every tool and the access it needs.

## What an agent can never do

No connection can delete apps, databases, buckets or domains, restore backups, change the plan, make payments, or manage members and API tokens. These actions stay in the [dashboard](https://instant.rw/dashboard), where a person makes them.

## How connecting works

<Steps>
  <Step title="Add Instant to your client">
    Follow the [setup for your client](/agents/connect). All it needs is the server URL.
  </Step>
  <Step title="Sign in">
    The client opens Instant in your browser. Sign in if you aren't already.
  </Step>
  <Step title="Choose the organization and access">
    Pick the organization the connection works in, then **Full access** or **Read only**, and select **Allow**. To work in another organization, connect again.
  </Step>
</Steps>

## Review and disconnect

Every change an agent makes appears in the organization's **Audit log** with the client that made it, so you can tell an agent's change from a person's.

To remove a connection, open **AI agents** in the dashboard, find it under **Connected** and select **Disconnect**. It stops working immediately.

## Other ways to give an agent access

- Agents that run shell commands, such as Claude Code, Codex and Cursor, can also use the [CLI](/cli/overview). Every command can print JSON.
- Clients that can't sign in through a browser, and CI jobs, can use an [API token](/api/tokens).
