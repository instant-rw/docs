Instant Cloud is the agent-native cloud. You bring the code, or ask your AI agent to, and Instant handles the servers, the builds and the HTTPS certificates. PostgreSQL, MySQL and Redis databases and S3-compatible storage run on the same private network as your apps, so connecting one takes a single click.

## What you can run

- **Apps.** Instant detects your framework and sets the build and start commands for you: Next.js, Nuxt, Astro, SvelteKit, Remix, Angular, NestJS, Express, Django, FastAPI, Laravel, Go, Rust, plain Node.js, Python and PHP, and static sites.
- **Databases.** PostgreSQL, MySQL and Redis with backups, metrics and a connection string written straight into your app's variables.
- **Storage.** S3-compatible buckets for uploads and files, with per-app access keys.
- **Domains.** Every app gets an `instant.rw` address. On a paid plan, add your own domain and Instant issues and renews its certificate.

When a build fails, your live version keeps serving. Instant reads the log and, for problems it recognises such as an out-of-date lockfile or a missing registry token, shows how to fix them. You can roll back to any earlier deployment.
