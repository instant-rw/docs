title: "API tokens"
description: "Create a token for CI, scripts and MCP clients that cannot sign in with a browser."
---

An API token lets a script or CI job use the CLI, the API or the MCP server without a browser sign-in.

## Create a token

<Steps>
  <Step title="Open AI agents">
    In the dashboard, go to AI agents, then API tokens, then Create token.
  </Step>
  <Step title="Set the name, access and expiry">
    Name the token after where it is used, such as `github-actions`. Choose Full access or Read only. Choose an expiry of 7, 30, 90 or 365 days, or never.
  </Step>
  <Step title="Copy the token">
    The token starts with `inst_` and is shown once. Store it as a secret right away.
  </Step>
</Steps>

## What a token can do

A token acts as the person who created it, in the one organization they created it in. Full access can change things. Read only can only read. Like an [MCP connection](/agents/overview), a token cannot delete apps, databases, buckets or domains, restore backups, change the plan, pay, or manage members or tokens.

A token stops working when it expires, when it is revoked, or when its creator leaves the organization.

## Use a token

With the CLI, set `INSTANT_TOKEN`. No `instant login` is needed.

```sh
INSTANT_TOKEN=inst_… instant deploy --app my-app --yes
```

With the API or the MCP server, send it as a bearer token:

```sh
curl https://api.instant.rw/v1/apps \
  -H "Authorization: Bearer inst_…"
```

`instant login --token inst_…` stores a token on your own computer instead.

## Deploy from GitHub Actions

Add the token as a repository secret named `INSTANT_TOKEN`, then:

```yaml
name: Deploy
on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm i -g instant-cloud
      - run: instant deploy --app my-app --yes
        env:
          INSTANT_TOKEN: ${{ secrets.INSTANT_TOKEN }}
```

The token needs Full access to deploy. See [Deploy a folder](/cli/deploy-a-folder) for what is uploaded.

## Revoke a token

In AI agents, then API tokens, revoke the token. It stops working at once. Members revoke their own tokens. Owners and admins can revoke any token in the organization.
