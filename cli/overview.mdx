The Instant CLI gives you the `instant` command. Deploy the project you're in, follow its logs, and manage variables, databases, buckets and domains without opening the dashboard. It runs on macOS, Linux and Windows, and the same commands work in CI and for AI agents that run shell commands.

## Install

<Tabs>
  <Tab title="macOS and Linux">
    ```sh
    curl -fsSL https://instant.rw/install.sh | sh
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    irm https://instant.rw/install.ps1 | iex
    ```
  </Tab>
  <Tab title="npm">
    Requires Node.js 20 or newer.

    ```sh
    npm i -g instant-cloud
    ```
  </Tab>
</Tabs>

Check the installation with `instant --version`. Update later with `instant upgrade`.

## Sign in

```sh
instant login
```

The CLI shows a code and opens [instant.rw/device](https://instant.rw/device) in your browser. Check that the code matches and approve it. On a machine without a browser, add `--no-browser` to print the link instead.

Your sign-in is stored in `~/.config/instant/auth.json` (`%APPDATA%\instant` on Windows). Run `instant whoami` to see the account, organization and access level in use, and `instant logout` to remove it.

## Choose an organization

One sign-in works in all your organizations.

```sh
instant orgs                  # list your organizations
instant switch my-team        # make my-team the default
instant apps --org my-team    # use another organization for one command
```

You can also set `INSTANT_ORG` for a whole shell session.

## Deploy your first project

```sh
cd my-project
instant deploy
```

The first time, the CLI offers to create an app or link an existing one, then uploads your code, streams the build log and prints the live address. [Deploy without Git](/deploy/without-git) explains what is uploaded and how rollbacks work.

## Everyday commands

```sh
instant status                       # the app and its latest deployment
instant logs -f                      # follow runtime logs
instant env set API_KEY=abc --secret # set a secret variable
instant db create main --engine postgres --connect my-app
instant domains add example.com      # prints the DNS records to create
instant rollback <deployment>        # redeploy an earlier deployment
```

See [Commands](/cli/commands) for every command and flag. Deleting apps, databases, buckets and domains is only possible in the dashboard.
